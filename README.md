# ♞ 오프닝 트레이너

내 오프닝 레퍼토리를 **간격 반복(spaced repetition)** 으로 외우는 웹 앱입니다.
상대 수는 앱이 자동으로 두고, 나는 레퍼토리에 있는 수를 맞혀야 합니다.

## 기본 레퍼토리 (115개 라인)

| 색 | 챕터 | 내용 |
|---|---|---|
| 백 | 이탈리안 게임 | 3...Bc5 4.c3 Nf6 5.d4 exd4 6.e5 센터 어택 (4...Qe7, 4...d6 대응 포함), 3...Nf6 4.Ng5 나이트 어택·프라이드 리버, 3...Be7, 3...d6, 3...Nd4 |
| 백 | 오픈게임 기타 | 페트로프(함정 포함), 필리도르, 다미아노 응징 |
| 백 | 프렌치 어드밴스 | 1.e4 e6 2.d4 d5 3.e5 c5 4.c3 … |
| 백 | 카로칸 3.Nc3 | 4...Bf5 / 4...Nd7 / 4...Nf6 |
| 백 | 스칸디나비안 2.exd5 | 2...Qxd5 3.Nc3 (Qa5 / Qd6 / Qd8 / Qe5+), 2...Nf6 3.d4 |
| 흑 | 이탈리안 상대하기 | 3.Bc4 Bc5 — 4.c3, 4.d3, 4.b4(에반스), 묄러 어택, 4.Ng5?, 4.Nxe5? |
| 흑 | 루이 로페즈·스카치 등 | 3.Bb5, 3.d4, 3.Nc3, 3.c3 |
| 흑 | 2수째 다른 수 | 2.Qh5(스콜라 메이트 막기), 2.Bc4, 비엔나, 킹스 갬빗, 센터 게임 |
| 흑 | 1.d4 Nf6 | 킹스 인디언 셋업 — 2.c4, 2.Nf3, 런던, 트롬포프스키, 2.Nc3 |

- 모든 라인은 **내 수로 끝나고**, 한 포지션에서 내 수가 둘로 갈리지 않습니다(테스트로 검사).
- 수마다 한국어 설명이 붙어 있습니다. 순서가 달라도 같은 포지션으로 합류(트랜스포지션)하면 같은 수를 둡니다.
- 라인은 Stockfish로 검사했습니다. 내 수가 크게 손해 보는 라인이 없도록 고쳤습니다.

## 훈련 방식

1. **새 라인 배우기**: 화살표를 따라 한 번 두고, 같은 세션 끝에서 화살표 없이 한 번 더 둡니다(확인 테스트).
2. **복습**: 실수 없이 끝내면 복습 간격이 1 → 3 → 7 → 14 → 30 → 60 → 120일로 늘어납니다. 틀리면 다음 날 다시 나옵니다.
3. 틀리면 한 번은 다시 생각할 기회를 주고, 또 틀리면 정답을 화살표로 보여 줍니다.
4. 복습 중에는 라인 이름을 감춰서 정답이 드러나지 않습니다.

## 내 라인 추가하기

‘라인 추가’에서 PGN이나 수순을 붙여 넣으면 됩니다.

- 괄호 변화 `( )`가 있으면 라인이 여러 개로 자동으로 나뉩니다(Lichess 스터디 PGN 그대로 가능).
- `{ }` 안의 글은 그 수의 설명으로 저장됩니다.
- 기존 레퍼토리와 충돌하면(같은 포지션에서 다른 수) 저장 전에 알려 줍니다.
- 안 쓰는 기본 라인은 챕터 화면에서 ‘숨기기’로 뺄 수 있습니다.

진도와 직접 추가한 라인은 **브라우저(localStorage)에만** 저장됩니다. 설정에서 백업 파일을 저장하거나 불러올 수 있습니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm test         # 레퍼토리 검사와 단위 테스트
npm run build    # dist/ 에 배포용 빌드
```

- 기본 레퍼토리: `src/data/repertoire.ts`
- 기술: React, TypeScript, Vite, [chess.js](https://github.com/jhlywa/chess.js), [react-chessboard](https://github.com/Clariity/react-chessboard)
